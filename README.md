# Тихий лист · Мини-маркет

Учебная чайная лавка на React, TypeScript и styled-components по домашнему заданию со слайда 34 презентации «Подходы к стилизации в React». На полке восемь сортов: их можно искать по названию, региону и вкусу, фильтровать по категории и добавлять в корзину. Внизу страницы есть лаборатория, где можно нажать на любой из 12 вариантов кнопки и увидеть соответствующий JSX.

## Запуск

Понадобятся **Node.js 24 LTS** (также поддерживается ветка 22 начиная с 22.12) и npm. Из папки, в которой лежит `package.json`, выполните:

```bash
npm ci
npm run dev
```

Откройте адрес из строки `Local` в терминале (обычно `http://localhost:5173`). Остановка — `Ctrl+C`.

| Команда | Результат |
| --- | --- |
| `npm run typecheck` | Проверка TypeScript без сборки |
| `npm run build` | Проверка типов и сборка сайта в `dist/` |
| `npm run preview` | Локальный просмотр готовой сборки после `build` |
| `npx playwright install chromium` | Однократная установка браузера для тестов |
| `npm test` | Браузерные проверки; тестовый сервер запускается автоматически |

Товары находятся в [`src/data/products.ts`](src/data/products.ts), палитры — в [`src/styles/theme.ts`](src/styles/theme.ts), компоненты UI-кита — в [`src/ui/`](src/ui/). Добавление имитирует запрос с задержкой 650 мс. Корзина живёт до перезагрузки страницы; явный выбор темы хранится в `localStorage`. В режиме «Как в системе» оформление следует настройке устройства.

## styled-components против CSS Modules на моём проекте

У кнопки покупки четыре варианта и три размера, поэтому в styled-components удобно выбирать два фрагмента CSS по пропсам `variant` и `size`. В CSS Modules я бы описал те же варианты локальными классами и собирал бы `className` в компоненте кнопки. При смене темы `ThemeProvider` передаёт новую палитру и кнопке, и карточке товара. С CSS Modules я мог бы переключать атрибут на `html` и менять значения CSS-переменных, сохраняя имена классов карточек. Преимущество текущей версии в том, что TypeScript сразу замечает опечатку в имени цветового токена. Преимущество CSS Modules для большого каталога — стили готовятся при сборке и для их генерации в браузере не нужна отдельная библиотека.

## Публикация для сдачи

Для деплоя в репозитории откройте **Settings → Pages → Source: GitHub Actions**, затем **Actions → Publish mini-market to GitHub Pages → Run workflow**. Ссылка на опубликованный сайт появится в окружении `github-pages` успешного запуска.
